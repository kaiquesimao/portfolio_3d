# Contributing

This repository is maintained solely by [@kaiquesimao](https://github.com/kaiquesimao).

## Policy

- Do not push directly to `master` or `development`.
- All changes must go through a pull request.
- Pull requests require approval from the code owner (`@kaiquesimao`).
- Force pushes and branch deletions on protected branches are blocked.
- External contributions are not expected; unsolicited PRs may be closed without merge.

## For the maintainer

1. Create a feature branch from `master`.
2. Open a pull request targeting `master`.
3. Wait for required checks (when configured).
4. Merge via the GitHub UI (bypass is allowed only through the PR merge flow).
